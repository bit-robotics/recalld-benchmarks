# Security Policy

## Scope

This repository contains benchmark tooling and committed benchmark reports. It
is not the Recalld service. Vulnerabilities in the Recalld API itself should go
to the same address below and will be routed internally.

## Reporting a vulnerability

Email **support@recalld.ai** with "Security" in the subject line. Please do not
open a public issue for anything exploitable.

Include what you did, what happened, and what you expected. We aim to acknowledge
within three working days.

## Credentials in this repository

The committed reports contain no API keys. They hold benchmark questions,
retrieved context, model answers and token counts only. If you believe a key has
been committed here, report it privately rather than opening an issue, and we
will rotate it before publishing a fix.
